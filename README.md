    📈 Stock Portfolio Tracker
</h1>

<h2 style="color: #34495E; font-size: 28px; margin-top: 30px; text-align: center;">
    🎯 Objective
</h2>
<p style="font-size: 18px; line-height: 1.8; color: #7F8C8D; padding: 0 20px;">
    The Stock Portfolio Tracker allows users to track their stock portfolio by providing real-time stock data. It fetches live data from the Yahoo Finance API, displaying the current price, profit/loss, and percentage change for each stock. The tracker also allows users to visualize stock trends via interactive graphs.
</p>

<h2 style="color: #34495E; font-size: 28px; text-align: center;">
    🛠️ Features
</h2>
<ul style="font-size: 18px; line-height: 1.8; color: #7F8C8D; list-style-type: square; padding-left: 40px;">
    <li>Real-time stock price updates</li>
    <li>Profit and loss calculation</li>
    <li>Interactive graphs to visualize stock trends</li>
    <li>Track multiple stocks simultaneously</li>
    <li>Customizable portfolio with add/remove functionality</li>
    <li>Responsive dark-themed interface for easy viewing</li>
</ul>

<h2 style="color: #34495E; font-size: 28px; text-align: center;">
    🧑‍💻 How It Works
</h2>
<p style="font-size: 18px; line-height: 1.8; color: #7F8C8D; padding: 0 20px;">
    To start tracking your portfolio, simply input the stock symbol in the designated field and click "Start Tracking". The app will automatically fetch the latest data for the stock, calculate the profit/loss, and display the information in an organized table. You can also view the stock's price trend by clicking the "📈 Graph" button.
</p>

<h2 style="color: #34495E; font-size: 28px; text-align: center;">
    🛠️ Tools and Technologies
</h2>
<ul style="font-size: 18px; line-height: 1.8; color: #7F8C8D; list-style-type: square; padding-left: 40px;">
    <li>Python</li>
    <li>tkinter (GUI Library)</li>
    <li>yfinance API (for live stock data)</li>
    <li>matplotlib (for plotting stock trends)</li>
    <li>JSON (for data handling)</li>
</ul>

<h2 style="color: #34495E; font-size: 28px; text-align: center;">
    🚀 Installation and Setup
</h2>
<p style="font-size: 18px; line-height: 1.8; color: #7F8C8D; padding: 0 20px;">
    To run the Stock Portfolio Tracker, follow these steps:
</p>
<ul style="font-size: 18px; line-height: 1.8; color: #7F8C8D; list-style-type: square; padding-left: 40px;">
    <li>Ensure Python 3.x is installed on your system</li>
    <li>Install necessary libraries using pip:
        <pre style="background-color: #f4f4f4; padding: 10px; font-size: 16px; border-radius: 5px;">pip install yfinance matplotlib</pre>
    </li>
    <li>Download or clone the repository</li>
    <li>Run the script and start adding stocks to your portfolio</li>
</ul>

<h2 style="color: #34495E; font-size: 28px; text-align: center;">
    ⚙️ Usage Instructions
</h2>
<ul style="font-size: 18px; line-height: 1.8; color: #7F8C8D; list-style-type: square; padding-left: 40px;">
    <li>Enter the stock symbol in the input field (e.g., AAPL, TSLA, GOOG)</li>
    <li>Click "Start Tracking" to add the stock to your portfolio</li>
    <li>Click the "📈 Graph" button to view an interactive chart of the stock's price trend</li>
    <li>Click "Refresh All Stats" to update all stock data in your portfolio</li>
    <li>Click "Delete" to remove a stock from your portfolio</li>
</ul>
